# Optimized wasm size budget per contract, in bytes: "<crate> <bytes>".
#
# Budget policy (ratchet):
#   - Each budget is the optimized wasm size at the time it was recorded + 10%.
#   - Budgets ratchet downward as code settles: when a contract shrinks,
#     lower its budget in the same PR.
#   - Raising a budget requires an explicit comment on the PR explaining why
#     the growth is necessary. check.sh fails when a contract's optimized wasm
#     exceeds its budget or when a contract has no budget recorded here.
#
# Regenerate after a deliberate change (and explain it in the PR):
#   scripts/wasm-size/check.sh --update <crate>
#
# `common` is a plain rlib and is intentionally excluded from this list.
# Test/adversary crates are native-only and are also excluded.
#

# refreshed on a machine with the wasm toolchain by running, for each crate:
#   (cd <crate> && cargo build --target wasm32-unknown-unknown --release)
#   scripts/wasm-size/check.sh --update <crate>
